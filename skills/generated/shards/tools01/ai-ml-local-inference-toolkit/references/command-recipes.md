# AI/ML Local Inference Toolkit Command Recipes

Use these as starting points. Adapt paths, namespaces, and credentials to the task context.

## 1. List Ollama models

```bash
ollama list
```

Check locally available model inventory.

## 2. Run Ollama prompt

```bash
ollama run llama3 "Summarize this dataset"
```

Execute local model completion.

## 3. Start JupyterLab

```bash
jupyter lab --no-browser
```

Launch notebook server for analysis.

## 4. Open IPython shell

```bash
ipython
```

Inspect and prototype quickly in REPL.

## 5. Login HuggingFace CLI

```bash
huggingface-cli login
```

Authenticate for model pull/push operations.
