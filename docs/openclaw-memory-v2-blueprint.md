## 1) Executive Summary

This blueprint upgrades the "always-on memory" pattern into a production-grade system for Zach's OpenClaw environment:

- **Always-on ingest** from workspace memory artifacts (MEMORY.md + daily logs + PARA folders)
- **Periodic consolidation** + nightly reconsolidation
- **Citation-first query** with hybrid ranking (keyword + recency + importance + confidence)
- **Strong operational controls** (localhost bind, auth token, approval-gated destructive actions, backups)

Primary goal: move from passive note retrieval to an **active memory operating loop** with measurable quality and clear ops ownership.

## 3) V2 Architecture

## 3.1 Pipeline Stages

1. **Ingest (5 min cadence)**
   - Parse memory sources
   - Normalize into structured records
   - Dedupe using content fingerprint
   - Persist provenance + confidence

2. **Consolidate (30 min cadence)**
   - Consume unconsolidated records
   - Generate cross-memory links and insights
   - Mark source records + write consolidation run

3. **Reconsolidate (nightly)**
   - Re-evaluate historical windows (60+ days)
   - Discover late-emerging connections
   - Compact low-signal clusters

4. **Query (on demand)**
   - Hybrid retrieval + ranking
   - Synthesize answer with citations
   - Record query/event telemetry

5. **Evaluate (daily)**
   - Citation coverage
   - Retrieval precision@k
   - Contradiction drift
   - Freshness SLA adherence

## 3.2 Core Security Posture

- API bind: **`127.0.0.1` only**
- Auth: mandatory bearer token for API write/delete endpoints
- Destructive ops (`/clear`, mass-delete): approval-gated
- Redaction pass before persistence (secrets/credentials/PII policy)
- Signed/append-only ops logs for incident replay

Why this matters:
- deterministic local persistence
- replayability
- easy backup/restore

## 6) Retrieval & Ranking Strategy

Use hybrid ranking with score composition:

- topic/query overlap (40%)
- recency decay (23%)
- importance (20%)
- confidence (12%)
- citation weight (5%)

Reference implementation:
- `scoreMemoryForQuery(...)` in `swarm-protocol/src/openclaw-memory-v2.ts`

Guardrails:
- always include citations when answering from memory
- return "insufficient evidence" if relevant score floor is not met
- prefer lower-confidence hedging over overconfident synthesis

## 11) Non-Negotiable Production Rules

- No public bind (`0.0.0.0`) without explicit reverse-proxy auth layer
- No destructive endpoint without approval and audit trail
- No memory answer without citations for non-trivial claims
- No schedule without failure alerts and retry policy
- No schema changes without migration + rollback path
